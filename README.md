
# Super Mario Engine (COAL Semester Project)

A 16-bit platform game in x86 Assembly (NASM) for DOSBox.

Course: EL2003

## Build

Open Command Prompt in the project root and run:

    build.bat

Creates `build\MARIO.COM`.

Requires NASM.

## Run

Open DOSBox and enter:

    mount c "C:\path\to\project\build"
    c:
    MARIO.COM
